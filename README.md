# Daily Devotional

A personal Catholic + Stoic daily devotional app.

## Current build
- Catholic, Stoic, Both, and Journal views
- Liturgical-season label
- Daily reflection structure
- Prayer and practice prompts
- Optional integration card
- Favorites
- Completion tracking and streaks
- Local journal storage
- Installable PWA structure
- Offline caching
- Sample entries for September 23–29

## Direction
The finished version will contain 365 Catholic reflections and 365 Stoic reflections, organized through the Catholic liturgical year and complementary virtue themes.

Catholic and Stoic ideas are intentionally kept distinct. The optional integration section only highlights practical points of contact.

## Privacy
Journal entries, favorites, and completion history are stored locally in the browser on the user's device and are not committed to this repository.
